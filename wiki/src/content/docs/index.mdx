`pi-delegation-policy` is a local Pi extension for delegation intensity and exact references for
Small, Medium, Large, and optional Visual Design. It guides the main agent; it never runs, routes, or
enforces delegated work.

:::caution
The extension adds guidance only when an active configuration is valid. It cannot guarantee that another system follows a configured role or thinking choice.
:::

## Start here

<Steps>

1. Install `pi-delegation-policy` and reload Pi.
2. Open `/delegate`, configure or explicitly disable each of Small, Medium, and Large, and leave at least one enabled. Visual Design is optional.
3. Select `normal`, `aggressive`, or `orchestrator`, choose **Apply changes**, then confirm `/delegate status` and `D:NORM`, `D:AGG`, or `D:ORCH`.

</Steps>

`orchestrator` minimizes main-agent execution and narration while retaining objectives, critical decisions, coordination, integration responsibility, evidence, and final acceptance. It batches transferable work without forcing recursive fanout. Published 0.7.0 supports all four intensities. Before downgrading to 0.6.0, set the global intensity and each active branch to `off`, `normal`, or `aggressive`; for `<=0.5.0`, also convert global defaults to schema 2 and replace ordinary `null` values with exact model references. `disabled` is distinct from `not configured`. The latter, an invalid enabled reference, or zero enabled ordinary roles produces `D:ERR` and injects no policy. Pi `0.84.3` is the explicitly checked baseline; the package peer range is `>=0.84.3`.
