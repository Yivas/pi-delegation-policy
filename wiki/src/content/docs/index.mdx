`pi-delegation-policy` is a local Pi extension for configuring delegation intensity and exact
references for Small, Medium, Large, and an optional UI Design role. It guides the main agent; it
does not run, route, or enforce delegated work.

:::caution
The extension cannot guarantee that another system follows a configured role or thinking choice. It
only adds guidance when the active configuration is valid.
:::

## Status

Version `0.1.1` is available from npm and supports Pi `0.84.1`. Every new session starts with
delegation set to `off`.

## Start here

- Follow the [installation guide](/pi-delegation-policy/getting-started/) to add the package to Pi.
- Read [configuration](/pi-delegation-policy/configuration/) before enabling an active intensity.
- Use [commands and status](/pi-delegation-policy/commands-and-status/) while operating the extension.
