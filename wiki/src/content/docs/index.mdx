`pi-delegation-policy` is a local Pi extension for configuring delegation intensity and exact
references for Small, Medium, Large, and an optional UI Design role. It guides the main agent; it
never runs, routes, or enforces delegated work.

:::caution
The extension cannot guarantee that another system follows a configured role or thinking choice. It
only adds guidance when the active configuration is valid.
:::

## Start here

<Steps>

1. Install `pi-delegation-policy` and reload Pi.
2. Open `/delegate`, set exact authenticated Small, Medium, and Large references, and optionally configure UI Design.
3. Select `normal` or `aggressive`, choose **Apply changes**, then confirm `/delegate status` and the footer show `D:NORM` or `D:AGG`.

</Steps>

The applied state is used on the next agent run. An invalid active role shows `D:ERR` and injects no
policy. Pi `0.84.1` is the explicitly validated baseline; the package peer range is `>=0.84.1`.
